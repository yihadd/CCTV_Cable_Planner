# CCTV Cable Planner

เว็บแอปสำหรับวางแผนติดตั้งกล้อง CCTV บนแผนที่ และประเมินระยะสายจากแนวที่วาด

## วิธีเปิดใช้งานบน Windows

1. ติดตั้ง Python 3 หากยังไม่มี
2. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ
3. ดับเบิลคลิก `start.bat`
4. เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

หาก Windows ไม่เปิดเบราว์เซอร์ให้อัตโนมัติ ให้คัดลอก URL ข้างต้นไปเปิดเอง  
หากพอร์ต 8000 ถูกใช้งานอยู่ ให้เปิด Terminal ในโฟลเดอร์นี้แล้วรัน `py -m http.server 8001` จากนั้นเปิด `http://localhost:8001`

## สิ่งที่ทำได้

- เพิ่มหมุด CCTV, NVR/Server, Switch/Rack, Junction Box, จุดหักเลี้ยว และจุดกำหนดเอง
- วาดแนวเดินสายจากหมุดเริ่มต้น เพิ่มจุดผ่าน/จุดเลี้ยว แล้วคลิกหมุดปลายทางเพื่อจบแนว
- วัดระยะเส้นตรงระหว่างสองจุด
- แสดงความยาวแนวสายและคำนวณสายสำรอง/ระยะเผื่อ
- แสดงรายการอุปกรณ์ แนวสาย และสรุประยะรวม
- บันทึก/เปิดโครงการในเบราว์เซอร์, Import/Export JSON, Export CSV และ PDF
- รองรับหน้าจอมือถือพร้อมแถบด้านข้างเปิด/ปิดได้

## การเปลี่ยนแปลงที่แก้ไขแล้ว

- **ปิดการแก้ไขแนวเดินสาย**: คลิกเส้นสายเพื่อเลือก/เน้นเส้นเท่านั้น ไม่เปิดหน้าต่างแก้ไข และไม่มีปุ่มแก้ไขเส้นสาย
- เปลี่ยนปุ่มในรายการแนวสายเป็นปุ่มลบพร้อมกล่องยืนยัน
- สรุประยะสายรวมจากแนวสายทุกเส้นในโครงการเพียงครั้งเดียว รวมสายหลัก/สายเชื่อมระหว่าง Switch ด้วย
- ตารางรายกล้องเลือกสายที่ปลายทางเป็นกล้องนั้น ไม่หยิบสายเส้นแรกที่กล้องเป็นต้นทางมาคิดผิด
- โหลดโครงการแล้วซิงก์ค่าร้อยละสายสำรองและค่าระยะเผื่อกลับเข้าหน้าจอ
- ตรวจสอบไฟล์ JSON ตอน Import/Load และป้องกันพิกัด Latitude/Longitude ที่อยู่นอกช่วง
- Undo การลากหมุดจะเก็บ snapshot ก่อนเริ่มลาก
- สร้างหมายเลขอุปกรณ์ถัดไปจากรหัสที่มีอยู่หลังเปิด/นำเข้าโครงการ เพื่อหลีกเลี่ยงรหัสซ้ำ
- ปรับขนาดแผนที่ใหม่หลังเปิด/ปิด Sidebar บนมือถือ

## วิธีวาดแนวสาย

1. เลือก **วาดแนวเดินสาย**
2. คลิกหมุดอุปกรณ์ต้นทาง เช่น Switch หรือ NVR
3. คลิกบนแผนที่เพื่อเพิ่มจุดผ่านหรือจุดเลี้ยวได้หลายจุด
4. คลิกหมุดอุปกรณ์ปลายทางเพื่อจบแนวสาย
5. เปิดแท็บ **อุปกรณ์** หรือ **สรุป** เพื่อตรวจสอบระยะ

แนวสายที่บันทึกแล้วไม่สามารถแก้ไขจุดหักเลี้ยวหรือเปลี่ยนต้นทาง/ปลายทางผ่านหน้าต่างแก้ไขได้ หากต้องการเปลี่ยนแนว ให้ลบเส้นเดิมและวาดใหม่  
การย้ายหมุดอุปกรณ์ในโหมดเลือกจะทำให้ปลายสายที่ต่อกับหมุดนั้นขยับตามตำแหน่งหมุด

## ข้อควรทราบ

- ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีและแผนที่จาก CDN/ผู้ให้บริการแผนที่
- แผนที่ถนนใช้ OpenStreetMap; ภาพถ่ายดาวเทียมและแผนที่ภูมิประเทศอาศัยบริการภายนอก ซึ่งอาจมีเงื่อนไขหรือข้อจำกัดการใช้งาน
- การค้นหาสถานที่ใช้ Nominatim และควรใช้อย่างสุภาพตามนโยบายการใช้งานของผู้ให้บริการ
- ระยะเป็นค่าประมาณจากพิกัดบนแผนที่ ไม่ได้รวมสิ่งกีดขวาง ความสูงจริง ท่อร้อยสาย หรือทางเดินภายในอาคารที่ไม่ได้วาดไว้ ต้องสำรวจหน้างานก่อนซื้อสาย
- การบันทึกโครงการอยู่ใน LocalStorage ของเบราว์เซอร์เครื่องนั้น ควร Export JSON สำรองไว้เป็นระยะ
- PDF ใช้หัวข้อภาษาอังกฤษเพื่อหลีกเลี่ยงปัญหาฟอนต์ภาษาไทยของ jsPDF ในเวอร์ชันต้นแบบ
